# Установка и обновление LVN Helper 4.9.2

## Требования
- Windows, GTA San Andreas, SA-MP, MoonLoader и функции SAMPFUNCS.
- `mimgui`, `encoding`, `vkeys`, `lib.samp.events` (SAMP.Lua), `ffi` (поставляется LuaJIT).
- Используйте официальные страницы проектов и проверенные источники для установки библиотек. Не запускайте неизвестные исполняемые файлы из чужих архивов.

## Чистая установка
1. Закройте GTA SA/SA-MP.
2. Проверьте, что MoonLoader установлен в папку игры и библиотеки доступны.
3. Распакуйте архив релиза; скопируйте `LVNHelper.lua` в `<папка GTA San Andreas>\moonloader\`.
4. Запустите игру через привычный лаунчер, введите `/lvn`.
5. Откройте «Настройки → Профиль сотрудника», впишите игровой ник и сохраните.

## Обновление
1. Сохраните старый `moonloader\LVNHelper.lua` и папку `moonloader\config\LVNHelper\` отдельно.
2. Замените `LVNHelper.lua` новым.
3. Не удаляйте свои файлы настроек, особенно `binds.json` и персональные данные хелпера.

## Если не работает
- Посмотрите `moonloader\moonloader.log`, найдите `LVN Helper`, `ERROR`, `mimgui` или `lib.samp.events`.
- Проверьте зависимости и их версии, затем протестируйте `/lvn`.
- Поддержка: https://t.me/XT0y4 ; GitHub Issues: https://github.com/Vampir2517/LVNHelper/issues
- Не выкладывайте публично пароли, токены, приватные ключи, полные логи или чувствительные личные данные.

## Особенности
- Скрипт ориентирован на Samp-RP HOME и может не работать на других серверах.
- Перед использованием возможных автоматических реакций и отправки игровых сообщений изучите правила своего сервера; не включайте их, если они запрещены.
- Проверка обновлений **не устанавливает обновление сама**. Она только сравнивает версии по `version.ini` в GitHub.

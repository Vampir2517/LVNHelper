# История изменений

## 4.9.3 — Проверка обновлений при запуске (14.11.2026)
- После входа в игру выполняется проверка `version.ini` на GitHub.
- При наличии более новой версии появляется отдельное окно **«Обновить» / «Позже»**.
- Скачивание происходит только после согласия игрока; перед заменой проверяется файл и создаётся резервная копия предыдущего Lua.
- После установки перезапускается только хелпер, без перезапуска GTA.
- Ручная проверка остаётся доступна через `/lvn` → «О скрипте».
- В публичной версии сохранена ссылка на тему [BlastHack](https://www.blast.hk/threads/259272/).
- **Beta:** необходимо протестировать работу установки в HOME Launcher.

- Подготовлены документация для GitHub, инструкция, релиз и шаблон ошибки.

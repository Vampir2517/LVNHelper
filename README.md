# LVN Helper — помощник сотрудников LV News (SA-MP)

**Версия:** 4.9.3 Public Beta  
**Автор:** Vampir2615 · **Telegram:** [@XT0y4](https://t.me/XT0y4)  
**GitHub:** [Vampir2517/LVNHelper](https://github.com/Vampir2517/LVNHelper)

> Независимый пользовательский Lua-скрипт для Samp-RP HOME; не официальный продукт проекта. Наличие и допустимость отдельных функций необходимо сверять с действующими правилами сервера. Beta: не проверен на всех конфигурациях HOME Launcher.

LVN Helper помогает вести эфиры, готовить рекламные объявления и RP-отыгровки, вести игровые викторины и интервью — с единым удобным окном `/lvn`.

## Проверка обновлений

Начиная с версии **4.9.3**, при входе в игру хелпер автоматически сверяет `version.ini` с GitHub. Только если найдена новая версия, появляется окно **«Обновить» / «Позже»**. Установка запускается исключительно после нажатия «Обновить»: файл скачивается с GitHub, проверяется, предыдущая версия сохраняется как резервная копия, после чего перезапускается скрипт. Настройки и `binds.json` не изменяются. Ручная проверка остаётся в `/lvn` → «О скрипте».

**Важно:** для перехода с **4.9.2 на 4.9.3** нужно один раз установить новую версию вручную — в 4.9.2 ещё нет автообновления. Новая функция пока не проверена непосредственно в HOME Launcher, поэтому 4.9.3 остаётся Beta.

## Основные возможности

- **Объявления:** шаблоны, предпросмотр текста, контроль редактирования; отправка готового черновика — под контролем пользователя.
- **322 рекламных слогана** из [темы LV News](https://samp-rp.su/threads/lv-news-reklamnye-slogany-organizacij-piar-biznesov.2660559/), 22 категории, поиск, быстрый доступ к СТО LS, Ферме №3 и эфирам, контроль длины.
- **Эфиры и сценарии:** встроенные заготовки для радиоведущего и тематических программ, вспомогательные инструменты.
- **«Битва умов»:** подготовка вопросов и ведение результатов в игровом эфире.
- **«Сан-Андреас за кадром»:** сохранённые сценарии.
- **Интервью «Один вопрос — весь штат»:** `/sv1` и `/sv2` с редактором внутри раздела «Отыгровки».
- **Персональный профиль:** ник берётся из настроек, старое имя ведущего не навязывается другим пользователям.
- **Редактируемые отыгровки и локальные настройки:** пользовательские изменения остаются в `moonloader/config/LVNHelper/`.
- **Информация о зависимостях, обновления и поддержка:** проверка версии при запуске, подтверждение скачивания, GitHub Issues, Telegram.

Важно: у хелпера есть опциональные функции, способные отправлять сообщения в игровой чат или выполнять игровые команды. Внимательно проверьте настройки перед использованием; не используйте функции, которые нарушают правила сервера. Зависимости и сторонние библиотеки в архив не включены.

## Установка

1. Установите совместимые GTA San Andreas + SA-MP, MoonLoader и SAMPFUNCS. На официальном HOME Launcher совместимость нужно проверить самостоятельно.
2. Убедитесь, что доступны библиотеки `mimgui`, `encoding`, `vkeys`, `lib.samp.events` (SAMP.Lua) и `ffi` (LuaJIT).
3. Скопируйте `LVNHelper.lua` в папку `GTA San Andreas/moonloader/`.
4. Перезапустите игру. Введите в чат **`/lvn`**.
5. В `Настройки → Профиль сотрудника` укажите свой игровой ник и сохраните.

Подробности, диагностика и резервное копирование в [INSTALL.md](INSTALL.md).

## Сохранение своих настроек

Перед обновлением скопируйте `moonloader/config/LVNHelper/` в безопасное место. **Не удаляйте `binds.json`**, иначе можете потерять отредактированные отыгровки.

# Помощь с LVN Helper

Баги и предложения можно оставлять в разделе [Issues](https://github.com/Vampir2517/LVNHelper/issues).

При сообщении об ошибке укажите версию, окружение и способ воспроизведения. Не прикладывайте личные данные или конфигурацию с секретами. Для исправлений желательно создать ветку и Pull Request с описанием изменения.

Перед добавлением чужих материалов проверьте право на распространение и условия лицензий.
